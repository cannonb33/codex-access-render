Connect to my PC ↗

Opens Chrome Remote Desktop. Sign in to the same Google account used on your PC, select your computer, and enter your PIN.

First visit? Set up this PC once.
  1. On your PC, open Chrome Remote Desktop and choose Set up remote access.
  2. Install the host, name your computer, and choose your own private PIN.
  3. Once your computer appears online there, return to this page from another device and connect.

Remote access must be set up before the button can connect you to this PC. On a phone, use the Chrome Remote Desktop app if prompted.
